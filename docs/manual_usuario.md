# Manual de Usuario - SecureFlow Dashboard

Bienvenido al portal de SecureFlow.

## Guía de Navegación

1. **Acceso al Portal:**
   - Abra el navegador e ingrese a `https://localhost/`.
   - Acepte la advertencia del certificado local si aparece.

2. **Verificación de Salud:**
   - Ingrese a `https://localhost/health` para consultar el estado del servicio.

3. **Documentación Interactivas (API Swagger):**
   - Acceda a `https://localhost/docs` para visualizar y probar endpoints REST.
